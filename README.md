# FIXMYCITY
# Namma Tamil Nadu

A front-end citizen complaint portal for reporting civic issues and tracking their status.

## Run locally

```powershell
python -m http.server 5500 --bind 127.0.0.1
```

Open `http://127.0.0.1:5500/index.html` for the public portal or `http://127.0.0.1:5500/officer.html` for the officer dashboard.

## Demo officer accounts

- `officer1` / `tn@2026`
- `officer2` / `tn@2026`
- `admin` / `admin@2026`

Data is stored in browser `localStorage`; it is not connected to a real government server.
